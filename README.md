### 🏗️ ¿Qué es Evidence Integrity OS?
No es solo un verificador de archivos. Es un **ecosistema descentralizado y offline-first** para la preservación, auditoría y certificación de evidencia digital. Diseñado para operar donde la confianza es crítica: desde la cadena de suministro industrial hasta la preservación de evidencia forense.

### 🧰 Stack Tecnológico
*   **Criptografía:** SHA-256, Merkle Trees, Web Crypto API.
*   **Frontend Core:** HTML5 + JS Vanilla (Zero dependencies).
*   **Entorno Cloud/DB:** Next.js, Supabase (PostgreSQL).
*   **IA Generativa:** Integración con modelos de difusión (Local & Cloud).
*   **Monorepo:** pnpm + Turborepo (Estructura Enterprise).

### 📂 Arquitectura
*   `/apps`: Interfaces web y dashboards.
*   `/packages`: Lógica compartida y SDKs.
*   `/services`: APIs y workers.
*   `/contracts`: Smart contracts (Solidity).
*   `/legal`: Registro de propiedad intelectual y compliance.

### 🤝 Filosofía 51 / 49
Construido bajo la premisa de que la IA (49%) potencia la velocidad y la criptografía, pero es el juicio humano (51%) quien firma la verdad.
