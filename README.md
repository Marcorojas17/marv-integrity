## 🛡️ El Protocolo KRONOS

*   **Integridad:** Todo archivo es verificado mediante criptografía SHA-256.
*   **Privacidad:** Los verificadores operan 100% offline. Los datos del usuario nunca salen de su dispositivo.
*   **Soberanía:** Construimos sobre estándares abiertos (HTML5, JS, Node.js, Web Crypto API) para no depender de monopolios corporativos.
